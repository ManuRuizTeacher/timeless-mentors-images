# Retratos de TimelessMentors

Solo imágenes. Este repo es **público** a propósito: la app enlaza las fotos desde aquí.
No subas nunca código, claves ni datos de alumnos.

## Añadir un retrato nuevo

1. **Add file → Upload files**: arrastra el PNG o JPG y pulsa *Commit changes*.
   Subir aquí no gasta créditos de Netlify; este repo no está conectado a la app.
2. Abre la imagen en GitHub, pulsa **Raw** y copia la dirección del navegador.
   Es de la forma `https://raw.githubusercontent.com/ManuRuizTeacher/timeless-mentors-images/main/Nombre.png`
3. En el panel de admin, pega esa dirección en el campo de imagen del mentor.

Consejo: cuanto más ligera, mejor carga en clase. Unos 768 px de ancho bastan
(por ejemplo, comprimiendo en squoosh.app antes de subir).
